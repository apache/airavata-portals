# Dependency Pins

## vue-slider-component @ 4.1.0-beta.7

Pinned to `4.1.0-beta.7` because Vue 3 support only exists on the 4.x beta series;
the 4.x line never reached a stable release. The package is effectively abandoned at
this version. Revisit when Track A decides on a component library (likely replacing
`vue-slider-component` entirely with the chosen library's slider primitive).
